Cloud write mode - Horses

Experimental phase: only horse profiles are saved to the cloud.

Horse data mode: Local

Horse cloud stable: -

  • This is an experimental phase.
  • Only horse profiles will be saved to the cloud.
  • Tasks, work hours, feed inventory, and calendar still stay local for now.
  • Local horse data will not be deleted.
  • You can return horse writes to local mode.

Horse cloud writes are disabled until you are logged in, have an active stable, and type HORSES CLOUD.

Cloud cleanup

Delete cloud rows for the active stable when cloud preview counts are duplicated or wrong.

Cleanup target stable: -

  • This can delete cloud rows for the active stable.
  • Local browser data will not be deleted.
  • Use this only if cloud preview counts are duplicated or wrong.
  • After cleanup, run manual upload again to copy local data back to cloud.

Cleanup is disabled until you are logged in, have an active stable, and type RESET CLOUD.
