Privacy

Privacy

A simple overview of where EquiTrack stores data and how accounts are managed.

  • EquiTrack stores user account data in Supabase.
  • Stable data is stored in Supabase cloud when you are logged in and Cloud mode is active.
  • Local browser data may also be stored as fallback or local backup.
  • EquiTrack does not sell user data.
  • EquiTrack does not use public sign-up.
  • Users are created by authorized admins or stable owners.
  • Export backups regularly if you use local fallback data.
  • For privacy questions, contact the EquiTrack administrator.
